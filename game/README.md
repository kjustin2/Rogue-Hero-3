# Lost Fiend

A compact isometric dungeon fighter. Read the tell, punish the opening, escape.

- WASD: move. Mouse: aim. Left click: slash. Right click: heavy. Space: dodge.
- Three short encounters, one boss, quick retry. No Tempo or overcharge.
- `npm start`: build and launch Electron.
- `npm run build`: production build. `npm test`: the single 30-second smoke.

See [current state](docs/RESET.md), [style and design decisions](docs/STYLE-AND-DESIGN.md),
and [project instructions](../AGENTS.md). Previous overhaul sources are preserved
outside this repo at `D:/SAAS2/Rogue-Hero-3-reference-20260920`.

Title includes Tutorial, Options and Continue at the saved chamber. Rooms advance
without upgrade choices. Continue resumes the current chamber after reopening;
sound volume is saved.
