# Lost Fiend

A compact isometric dungeon fighter. Slash, commit a heavy strike, dodge the reply.

The September 2026 reset replaces the previous expansive overhaul. See
[project instructions](AGENTS.md), [current state](game/docs/RESET.md), and
[style and design decisions](game/docs/STYLE-AND-DESIGN.md).

Run: `cd game`, `npm install`, `npm start`.
Build: `npm run build`. Quick smoke: `npm test` (30-second deadline).
